Saltline Cover Studio turns your own photos into multi-panel, GTA-style cover posters. Every cover is built like real key art: a masthead band with five gold stars, a pull-quote and an issue chip; a slanted character callout on every panel (THE DRIVER, THE FIXER, THE RIDER…) that you can retype per panel; a huge chrome retro-stripe title with a neon script subtitle and a tagline ribbon; and a credits strip with billing block, barcode and an ORIGINAL COVER ART seal. Ten layouts — the wide Key Art, portrait Poster and square Ensemble poster grids plus seven classic collages — frame eight bundled sample photos (or your own, via picker or drag & drop) with saliency smart crop, per-panel drag and scroll-zoom framing, undo/redo and a one-click Auto Cover. Colour comes from the Key Art grade — a warm sunset gradient map with a gentle posterize that keeps faces clean — six further gradient grades, or an Auto grade fitted to your hero photo, with optional poster ink and halftone. Export is one click to PNG at 1080×1080, 1080×1350, 1920×1080 or 1080×1920. Everything runs locally in the browser: no uploads, no network, no build step.

## Run it

```sh
node main.ts
```

That copies the app and its screenshots into the output directory and writes the dossier. To use the studio itself, serve the app folder and open it in a desktop browser:

```sh
node serve.ts
# then open http://localhost:8080
```
